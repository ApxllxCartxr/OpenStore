# Public codes travel with the agent; private codes never do

A Merchant runs two kinds of code and they have opposite threat models. A public code is advertised — printed on a card, posted on Instagram, typed by anyone — so there is nothing to protect and an agent may carry it freely. A private code is a single recipient's compensation, apology, or winback, and its value is precisely that nobody else has it. Treating them identically means either crippling public codes or handing private ones to every stranger agent that touches the basket.

So visibility is a property of the code (`public` / `private`, a closed set), and it decides the path. Public codes are collected by the Buyer Agent on the checkout card and ride through door 9 like any other Quote input. Private codes are refused there and entered only on the same-domain approve page — a `Have a code?` field beside the total — where applying one re-calls `quote`, re-renders the new total, and *then* binds the tap to it. The code never transits the agent, never lands in a chat transcript, and the Consumer still taps the exact number they were shown. Private codes are single-use by default and must clear a minimum-entropy check at creation, because a guessable private code is a public one.

Enumeration is the shared risk, since door 9 will happily answer "is this a code?" all day. Every wrong code — unknown, expired, exhausted, ineligible — refuses as the same `code-invalid` with no timing or message tell, under per-agent and per-order attempt caps. Consumption is Merchant-owned like every other piece of truth: the code is reserved inside `reserve` under the existing idempotency key and returned by `release`, so two concurrent baskets cannot spend one single-use code and no new door appears.

Consequences: `/agentic/approve` gains a pre-tap re-quote path, which is the first thing that changes a total after the cart is built — it is safe only because the tap binds the *post*-application `cart_hash`, never the earlier one. The demo chat therefore cannot demonstrate a private code inside the chat, which is the point and is asserted rather than apologised for. A Merchant who wants a code an agent can advertise marks it public and accepts that agents will share it.
